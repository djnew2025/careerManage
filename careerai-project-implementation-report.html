🚀 Quick Start

Node.js 18+ required. The app runs fully in demo mode — no database, no AI key, no GitHub token needed.

1. Install dependencies

cd backend && npm install
cd ../frontend && npm install

2. Configure environment (optional for full AI)

cd backend
cp .env.example .env
# Edit .env — only JWT_SECRET is required for production
# Leave OPENAI_API_KEY and DATABASE_URL blank for demo mode

3. Start the application

# Terminal 1: Backend
cd backend && npm run dev

# Terminal 2: Frontend
cd frontend && npm run dev

# Open http://localhost:3000

4. Try the demo

Click "Try Demo" on the landing page
→ No registration required
→ Full dashboard with Alex Sharma's demo data
→ All 24 features accessible immediately

5. Run tests

cd backend && npm test

6. Docker Compose (full stack)

docker-compose up --build
# Starts: PostgreSQL + Backend + Frontend

⚠️ Known Limitations

  • Demo mode uses pre-defined realistic data for Alex Sharma — not dynamically computed without a real AI API
  • Without PostgreSQL, all data is in-memory and resets on server restart
  • GitHub API: 60 unauthenticated requests/hour (set GITHUB_TOKEN for 5000/hour)
  • Real-time voice interview (Web Speech API) is UI-scaffolded; text mode is the default path
  • Course URLs point to skillsbuild.org (illustrative) — not direct enrollment deep links
